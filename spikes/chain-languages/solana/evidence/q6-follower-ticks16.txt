== rollback ==
NOT forced: solana-test-validator is a single node producing one linear chain, so no fork or dropped block can be provoked locally.
Real-chain semantics: processed = in a block the node just saw (may sit on a fork that is dropped); confirmed = supermajority voted (~2/3 stake; practically never reverted, not formally final); finalized = 31+ confirmed blocks on top (rooted: irreversible). A tx that was only `processed` can vanish with no error: the blockhash then expires (150 blocks) and the signature is never found.
