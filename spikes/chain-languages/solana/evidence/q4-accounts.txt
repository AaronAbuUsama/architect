== where each fact lives ==
admin / gate        : Workshop PDA [workshop, admin]               (config account, program-owned)
membership          : Member PDA [member, workshop, wallet]        (exists <=> member; absent account IS the 'not a member' state)
proposal + tally    : Proposal PDA [proposal, workshop, id u64 LE] (digest, yes, no, state; the tally is public: anyone can read the account)
one-vote fact       : VoteRecord PDA [vote, proposal, wallet]      (existence or voted flag)

== what the client can and cannot know ==
derives alone : every PDA address above, from (program id, admin wallet, proposal id, voter wallet): no chain read
cannot know   : whether a PDA exists (needs getAccountInfo), whether the workshop is gated (needs Workshop.gate_mint), which token account to pass for the gate
               (ATA is the convention, not a rule), the rent a not-yet-existing account will cost (depends on size, known from the IDL types but not exposed as a number)
               which accounts a THIRD-PARTY program will touch in a CPI: the caller must list them all (remaining accounts); the IDL cannot say
on EVM the same call needs only (contract address, function, args)
