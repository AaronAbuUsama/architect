Support desk

One long-running manager. It spawns a worker thread per ticket from the presets below. Workers live under a background boundary, so stopping the manager's run never kills them, and each one reports back as a follow-up.

The manager's delegation tool

subagent.spawnStart a worker thread from a preset with a task.
subagent.messageSteer a running worker, or queue a follow-up.
subagent.waitBlock the manager's run until a worker answers.
subagent.stopAbort a worker and everything it owns.
subagent.listLive workers with status and last report.
Replay safe: each call carries a requestId, so a restart finds the same worker and message instead of sending twice.
