Packages

The package map, decided in M0-packages.md under K2 question 4: one front door, plus one package per plugin, language and host. The old names, and which package each one became, are in that record.

Milestone M0 renames the code to match this page: M0.02 renames packages and imports, M0.03 the command, folders and variables. Until they land, the code on main still carries the old names. Nothing is published to npm before M7; only the local Verdaccio sees these names, so any of them can still change.

The workspace and its gates are private packages, @formants/source and @formants/e2e.

A project imports the front door and nothing else of the framework's:

import { Blueprint } from "@formants/forman";

Plugins come later, one package each

Named for what they are, without the kind: @formants/auth, @formants/organizations (M2), @formants/work (M3), @formants/agents (M4), @formants/stripe, @formants/resend (M5), @formants/wallets (M6). Languages and hosts keep their kind as a prefix (language-, host-), because a project picks one of each and the prefix tells them apart. See plugins.

The command

The command is forman (and forman-model for the compiler). It ships from @formants/cli until M2.09, because the front door cannot carry the bin without a cycle: forman needs cli, cli needs compiler, and compiler needs forman. Which internal packages ship inside the front door is settled in M2.09, when npm create formants replaces the preset and a new project should need one dependency.

Package rules

These are checked by lint and check, in Nx tags:

  • scope:forman (the front door) depends only on Effect.
  • Generated code imports only the target's runtime, the front door, the host and project code.
  • compiler and generators never run in production.
  • A project (scope:project) depends only on scope:forman, scope:language and scope:host.
  • Dependency versions are pinned exactly, and published at least three days before they are added.
  • Inside each package, src/ follows the six-slot module shape: main.ts as the only entry file, and modules/<name>/{README.md,types.ts,service.ts,internal/,<name>.test.ts}, no source file over about 250 lines.
