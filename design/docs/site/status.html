Where it stands

Eight milestones, M0 to M7, written on 17 November 2026. The full list, with every slice and its check, is design/milestones.md. This page is the short version.

Forman is the only focus until it is workable, at the end of M2. From there, Capxul's plugins are built on it, small and reusable. Nothing in a milestone starts until the one before it has passed its gate on main.

What exists on main

  • Declare and call. Things, machines, operations, roles, events, journeys and starting worlds in blueprint/; the compiler, the model, and the generated server, SDK, CLI, MCP, docs and portal.
  • Prove and ship. Worlds, journeys and nine evals; verdicts signed by CI into the logbook; versions from the model diff; promote, publish to a local registry, and watch.
  • Auth. Better Auth on D1: people, sessions, API keys, the device flow, OAuth for remote MCP.
  • Examples. examples/acme (the allowance) and examples/work.
  • Everything runs locally. There is no cloud yet.
  • Not built anywhere: plugins and mounts, adapters, the agent, service and system principals, secrets read by handlers, the agents feature, the factory loop, a Solidity language beyond a placeholder, and any cloud destination.

How these docs are built

Pages are Markdown in design/docs/pages/. design/docs/build.mjs turns them into design/docs/site/, which is committed so the docs can be read from the repository without building. design/docs/links.mjs checks every relative link and anchor in the built pages, and fails if the retired words or old names appear anywhere under design/docs/.

pnpm nx run docs:build    write design/docs/site/
pnpm nx run docs:check    fresh build equals committed output, then the link check
