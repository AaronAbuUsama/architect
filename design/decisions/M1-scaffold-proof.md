# M1 scaffold proof

Acme's `revoke then spend` starts from `funded`. Its lineage calls organization creation and allowance grant to
write the records that role and machine checks read. Substituting those setup calls would stop the journey before
its first step. Empty proof makes the declared starting world with the real handlers, then serves each journey
call through a freshly rendered scaffold inside the same World. Reads and the operation wrapper keep their
declared behavior. The route switch exists only in the temporary local Worker, and the run records no verdicts in
the project's ledger.

Plain local proof receives workerd's OTLP in a scoped loopback receiver. It writes the same JSON lines read by
the file trace source and strips private and personal attributes before writing. Explicit viewer runs and
attested environments use their existing collector. Empty proof exports only to its own local collector unless
the viewer is explicitly requested, and removes its temporary world and traces after reporting.

The author check on acme's existing journey found two red steps and one description proof. It also checked
that the original files were unchanged and the Worker stopped.
