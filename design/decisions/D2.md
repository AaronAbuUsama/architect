# D2: the layer-one primitives, and stage one's slice of acme

Decided 16 November 2026 by the builder (Aaron gave architectural ownership). Evidence: the worked example in
`design/docs/index.html`, `design/spikes/names-from-paths.md`.

## The build plan's four recommendations stand

1. **Moves with several outcomes:** `to` takes a list. The handler picks the outcome, and the runtime checks it
   against the list.
2. **Reads:** `Blueprint.read`, answered from the thing's records, with no handler.
3. **Idempotency:** `idempotent: "request"`, keyed by a request-key header. A retry replays the stored answer.
4. **Starting worlds** run declared operations and never write rows.

## Fixed while reading the design against AGENTS.md

5. **Steps take their names from their keys, not from strings.** The docs wrote
   `steps: [Blueprint.step.database("allowance.grant.insert")]`, which writes a declared name as a string. It is now
   `steps: { insert: Blueprint.step.database() }`. The compiler names the step `allowance.grant.insert` from the path
   and the key, and the handler calls `steps.insert(...)`, as the docs' handlers already did. The docs are updated to
   match.
6. **Field paths in roles stay typed strings.** `owner.of("organization")` names a field of the payload, checked by
   TypeScript against the payload's keys. A field key isn't a declared name.

## Stage one's slice of acme

Stage one proves the whole chain on real operations, not on one in isolation:

- **Things:** `person` (fields only; people arrive through sign-in in stage two), `organization` (verb `create`; its
  creator is its owner; role `owner`), and `allowance` (verb `grant`; machine with the `grant` move into `active`;
  event `AllowanceGranted`).
- **A data refusal on grant:** `AllowanceLimitTooHigh`, exit 44, when the limit is over the organisation's cap. Grant
  then has a declared error and a deciding log, so every eval has something real to judge in stage one.
- **Principals:** the world issues each journey's cast a real signed token (HMAC through WebCrypto inside the world
  Durable Object), carrying `person`. Better Auth replaces the issuer in stage two, and the rest stays the same.
- **Starting world `founded`:** ada runs `organization.create`. Journey `grant-an-allowance`: ada grants olga 500;
  bob is refused (`NotAllowed`) and the handler never runs; a limit over the cap is refused with
  `AllowanceLimitTooHigh`.

## Settled while building L1.10

7. **Imports inside a package go through Node subpath imports:** `#modules/<module>/<file>.ts`, declared in the
   package's `package.json` `imports`. That follows `~/AGENTS.md`, which says to use an alias and never `../..`, and it
   resolves the same way under tsc, vitest, Node and wrangler's bundler, since each package resolves its own `#`. A
   `~/` tsconfig path wouldn't, because packages are consumed as source. The Nx boundary rule runs with
   `allowCircularSelfDependency: true` so that it accepts these. Test files (`*.test.ts`) may also import
   `vitest`.
8. **No module imports another module's `internal/`.** `structOf` is exported from `things/service.ts` for events,
   errors and operations. Lint will enforce this rule (L1.40).
9. **Roles of different things compare as `Role<any>`.** A role's rule takes its own thing's instance, so a list of
   roles from different things can only be typed loosely. The precise check is on the path: `owner.of("organization")`
   must name a payload field, or the operation doesn't compile.
